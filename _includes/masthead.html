{%- comment -%} The masthead — 2026-08-05, rebuilt on arc42.org's pattern. Structure: brand · priority row (3) · CTA · DE/EN · "Mehr" drawer · search. Data: _data/navigation.yml (main / cta / drawer). Order and shape follow arc42.org's band (2026-08-05): logo alone at the left, links, then the control cluster on the right. Search sits at the far right rather than in the middle of that cluster - arc42.org has no search in its band at all, so there is no position to copy, and last is where it stops splitting the CTA from the language switch. WHAT THIS REPLACED, and why it is not a restyle of the old bar: The previous masthead was the theme's greedy-nav — seven links of identical weight, colour and size, with overflow handled by JavaScript that moved the LAST
  • into a hidden menu until the row fit. Three consequences: 1. No rangfolge. The commercial path (Termine -> Schulungen -> Anmeldung) rendered exactly like "Über...". 2. The visible link set depended on viewport width, so no stable mental model could form — what a visitor saw last time might not be there. 3. Overflow ate from the END of the list, and the list ended ... Download, "Über...", "Suche". The three items the deep-link visitor needs most were the three sacrificed first. The greedy-nav plugin lives in the committed assets/js/main.min.js and binds to `.greedy-nav`. This component is `.arc42-nav`, so the plugin finds nothing and does nothing. Do not reintroduce the `greedy-nav` class here unless you want the width-dependent shuffling back. The band is the family masthead fill #2b3a57 (BRAND.md -> Signature hues; arc42.de is the hub twin and shares arc42.org's navy). This is the masthead band ONLY — the rest of the family migration (Libre Caslon + Atkinson type pair, flat-paper surfaces, 65-75ch measure) is still queued for this site. All styling sits in assets/css/arc42-de.css under one banner comment so it can be lifted out in a single block. `id="site-nav"` is kept: _includes/skip-links.html targets it. Behaviour (drawer toggle, "/" hotkey, aria state) is in assets/js/arc42-nav.js. Without JavaScript the drawer stays open as a plain list and the search field still submits to /search/ as an ordinary form. {%- endcomment -%} {%- assign nav_main = site.data.navigation.main -%} {%- assign nav_cta = site.data.navigation.cta -%} {%- assign nav_drawer = site.data.navigation.drawer -%}
